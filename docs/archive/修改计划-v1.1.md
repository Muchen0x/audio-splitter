## 3. B1 — 左右链路同类告警去重（P0）

### 3.1 问题

`AudioEngine.Start`（2205/2206）把同一个 `log` 传给左右两个 `DriftCorrectingProvider`，两个 provider 各自限流 → 同一现象打两条。日志实证：

```
21:50:37.814 [WARNING] [警告] 缓冲水位偏低: 调节水位 28ms / 目标 95ms (低于 30%)，可能出现欠载断音
21:50:37.819 [WARNING] [警告] 缓冲水位偏低: 调节水位 28ms / 目标 95ms (低于 30%)，可能出现欠载断音
21:50:49.694 [WARNING] [警告] 时钟校正已触顶 -5000ppm ... 
21:50:49.828 [WARNING] [警告] 时钟校正已触顶 -5000ppm ...
```

### 3.2 设计决策

- **只在引擎层去重，不动 `DriftCorrectingProvider`**（该文件正在被调音验证，避免引入变量）。
- **只把去重器传给两个 provider**，`Start` / `Split` / `RaiseStalled` 仍用原 `log` —— 避免误伤启动日志。
- 去重键 = 消息的「类别前缀」（截到第一个 `:`、`(`、数字、`+`、`-` 之前）。同一类告警 1.5 秒内只出一条。

类别提取示例：

| 原消息 | 去重键 |
|---|---|
| `[警告] 缓冲水位偏低: 调节水位 28ms / 目标 95ms (低于 30%)…` | `[警告] 缓冲水位偏低` |
| `[警告] 时钟校正已触顶 -5000ppm (调节水位 53ms…)` | `[警告] 时钟校正已触顶` |
| `[警告] 输出线程取数据迟到 25ms (期望约 10ms)…` | `[警告] 输出线程取数据迟到` |
| `[状态] 缓冲水位已恢复: 57ms / 目标 95ms` | `[状态] 缓冲水位已恢复` |

> 左右两路的具体数值差异（调节水位 53ms vs 54ms）由**状态行**承载 —— `BufferStatus()` 里已有 `左迟到 N次/最大 Xms  右迟到 …` 的分侧展示，告警行合并成一条不丢信息。

### 3.3 代码（`StereoSplitterGUI.cs`，`AudioEngine` 类内）

在字段区（约 2073 行 `lastOverflowWarnTick` 之后）新增：

```csharp
// ---- 告警去重: 左右两路 provider 各自限流, 同一现象会打两条 ----
readonly object logGate = new object();
readonly Dictionary<string, int> logCategoryTick = new Dictionary<string, int>();

/// <summary>按告警类别 1.5s 去重: 左右两路同时触发同一类告警时只留第一条。</summary>
void LogThrottled(string msg)
{
    if (msg == null || log == null) return;
    string key = CategoryKey(msg);
    int now = Environment.TickCount;
    lock (logGate)
    {
        int last;
        if (logCategoryTick.TryGetValue(key, out last) && unchecked(now - last) < 1500) return;
        logCategoryTick[key] = now;
        if (logCategoryTick.Count > 64) logCategoryTick.Clear();   // 防无界增长
    }
    try { log(msg); } catch { }
}

/// <summary>"[警告] 缓冲水位偏低: 调节水位 28ms …" → "[警告] 缓冲水位偏低"</summary>
static string CategoryKey(string msg)
{
    int n = 0;
    while (n < msg.Length && n < 40)
    {
        char c = msg[n];
        if (c == ':' || c == '(' || c == '+' || c == '-' || (c >= '0' && c <= '9')) break;
        n++;
    }
    return msg.Substring(0, n).TrimEnd();
}
```

构造 `provider` 处（2205/2206）改为：

```csharp
leftProvider  = new DriftCorrectingProvider(leftBuf,  driftTargetSamples, driftMode, fixedPpm, LogThrottled);
rightProvider = new DriftCorrectingProvider(rightBuf, driftTargetSamples, driftMode, fixedPpm, LogThrottled);
```

```csharp
/// <summary>按插入顺序原子写盘。失败时通过 error 返回原因 (由调用方决定如何告知用户)。</summary>
public bool WriteAll(out string error)
{
    error = null;
    try
    {
        var sb = new StringBuilder();
        for (int i = 0; i < order.Count; i++)
        {
            string key = order[i];
            string val;
            if (!values.TryGetValue(key, out val)) continue;
            sb.Append(key).Append('=').Append(val).Append("\r\n");
        }

        string tmp = path + ".tmp";
        // 无 BOM: 与旧版文件保持一致, 否则首个键名会被 BOM 污染导致读取失配
        File.WriteAllText(tmp, sb.ToString(), new UTF8Encoding(false));
        if (File.Exists(path)) File.Replace(tmp, path, null);
        else File.Move(tmp, path);
        return true;
    }
    catch (Exception ex)
    {
        error = ex.GetType().Name + ": " + ex.Message;
        return false;
    }
}

public bool WriteAll()
{
    string ignored;
    return WriteAll(out ignored);
}
```

## 5. B3 — `AudioEngine.Dispose` 幂等（P0）

### 5.1 问题

`AudioEngine.Dispose()`（2506 行）里 `loopback.Dispose()`（2509）、`leftOut.Dispose()` / `rightOut.Dispose()`（2516/2517）不在 `try` 内、也不置 `null`。
`GiveUp` / `StopEngine` / `FormClosing` 三条路径都会走到，目前只靠 `TearDownEngine` 的 `catch {}` 兜着 —— 异常被吞掉，设备可能没释放干净，且掩盖真实故障。

### 5.2 代码

```csharp
bool disposed;

public void Dispose()
{
    if (disposed) return;
    disposed = true;

    try { Stop(); } catch { }

    if (loopback != null) { try { loopback.Dispose(); } catch { } loopback = null; }
    // 采集线程已退出 (StopRecording 等待其结束) → 此时释放等待句柄无竞态
    if (dataReady != null) { try { dataReady.Close(); } catch { } dataReady = null; }
    if (leftOut != null) { try { leftOut.Dispose(); } catch { } leftOut = null; }
    if (rightOut != null) { try { rightOut.Dispose(); } catch { } rightOut = null; }

    // 三个 MMDevice 均由本引擎自建 → 由本引擎释放
    if (captureDev != null) { try { captureDev.Dispose(); } catch { } captureDev = null; }
    if (leftDev != null) { try { leftDev.Dispose(); } catch { } leftDev = null; }
    if (rightDev != null) { try { rightDev.Dispose(); } catch { } rightDev = null; }
}
```

> 注意：`Stop()` 内部已有 `if (loopback != null)` 与逐项 `try`，保持不变；`stopping` 标志不需要复位（引擎一次性使用）。

## 6. B4 — `crash_*.log` 纳入清理（P0）

### 6.1 问题

`SessionLog.PruneOldLogs`（89 行）两处 `GetFiles("session_*.log")` 只清理会话日志，`crash_*.log` 永久累积。

### 6.2 代码

```csharp
static void PruneOldLogs(string logDir)
{
    try
    {
        var dir = new DirectoryInfo(logDir);
        // 覆盖 session_*.log 与 crash_*.log: 崩溃日志同样会无限累积
        var files = dir.GetFiles("*.log");
        DateTime cutoff = DateTime.Now.AddDays(-7);
        foreach (var fi in files)
            if (fi.LastWriteTime < cutoff) { try { fi.Delete(); } catch { } }

        files = dir.GetFiles("*.log");
        if (files.Length > 100)
        {
            Array.Sort(files, delegate(FileInfo a, FileInfo b) { return a.LastWriteTime.CompareTo(b.LastWriteTime); });
            for (int i = 0; i < files.Length - 100; i++)
            { try { files[i].Delete(); } catch { } }
        }
    }
    catch { }
}
```

```csharp
static void TrimTo(BufferedWaveProvider buf, int targetBytes)
{
    int excess = buf.BufferedBytes - targetBytes;
    if (excess <= 0) return;
    var tmp = new byte[4096];                      // 固定小缓冲, 不再按 excess 分配
    while (excess > 0)
    {
        int got = buf.Read(tmp, 0, Math.Min(excess, tmp.Length));
        if (got <= 0) break;
        excess -= got;
    }
}
```

### 8.4 6.4 代码

```csharp
/// <summary>一次枚举校验多个端点是否仍活动; 返回第一个缺失的 ID, 全部在位返回 null。
/// 枚举失败一律按「都在」处理, 避免误判触发重建。</summary>
static string FindMissingEndpoint(params string[] ids)
{
    if (ids == null || ids.Length == 0) return null;
    var missing = new List<string>(ids);
    try
    {
        using (var enumerator = new MMDeviceEnumerator())
        {
            var coll = enumerator.EnumerateAudioEndPoints(DataFlow.Render, DeviceState.Active);
            for (int i = 0; i < coll.Count && missing.Count > 0; i++)
            {
                string id = null;
                try { id = coll[i].ID; } catch { }
                if (id != null) missing.Remove(id);
            }
        }
    }
    catch { return null; }
    return missing.Count > 0 ? missing[0] : null;
}
```
