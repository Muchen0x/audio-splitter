# Stereo Splitter

把系统正在播放的立体声**拆成左右两路**，分别送到两个不同的输出设备上，各自独立调节延迟、音量和静音。

典型用途：两个人各戴一副耳机（或一副耳机 + 一个音箱）听同一份声音，一边只听左声道、另一边只听右声道；也可以把左右声道送到两个不同房间的设备上。因为左右两路是**独立设备、独立时钟**，程序内部带有闭环漂移校正，长时间播放不会渐渐错位、也不会偏音。

> 面向 Windows 的桌面小工具，WinForms + NAudio，单文件 exe 即可运行。

---

## 工作原理

```
系统播放 ──► 虚拟声卡(捕获端) ──loopback──┐
                                          │  分左右声道
                                          ├──► 左延迟线 ──► 左输出设备
                                          └──► 右延迟线 ──► 右输出设备
```

1. 用 WASAPI loopback 从**虚拟声卡**的捕获端点抓取系统混音（默认 48 kHz / 16 bit / 立体声）。
2. 按声道拆开，分别写入左右两条独立的延迟线（用于对齐两台设备之间的物理延迟差）。
3. 左右各用一个 `WasapiOut` 送到所选设备，缓冲水位由闭环校正环统一盯住：水位偏低就微调重采样比率拉回，避免欠载爆音或缓冲堆积导致延迟越来越大。
4. 左右校正共享同一份比例决策（`DriftCorrectionShared`），保证两边时钟即使略有差异也走同一条曲线，避免"一边快一边慢"造成的声像偏移。

## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（Windows 7 未验证） |
| 运行时 | .NET Framework 4.8 |
| 捕获端 | **一个虚拟声卡**（如 VB-Audio Virtual Cable、VoiceMeeter 等），需自行安装 |
| 输出端 | 任意两个可独立发声的输出设备（板载 3.5mm、USB 声卡、蓝牙、HDMI 等） |

> 仓库**不包含**任何虚拟声卡驱动，请到对应厂商官网下载安装。安装后把系统默认播放设备设为该虚拟声卡，程序再从它的捕获端点取音。

## 构建

需要 .NET SDK（6.0 或更高，用于 `dotnet build` 编译 net48 目标）：

```bat
build.cmd
```

脚本会依次 restore → 编译 Release → 校验 NAudio 是否已内嵌 → 把成品同步到仓库根目录 `SplitterGUI.exe`。

`verify.cmd` 在构建之上额外检查源码是否有未提交改动、并统计 `log/` 体积。

NAudio（`NAudio.Core` / `NAudio.Wasapi` 2.2.1）以嵌入资源方式打进 exe，**发布时只需要一个 `SplitterGUI.exe`**，无需附带 dll。

## 使用

1. 安装并启用一个虚拟声卡，把系统默认播放设备切到它。
2. 启动 `SplitterGUI.exe`：
   - **捕获(虚拟)**：选择虚拟声卡的捕获端点。
   - **左 / 右声道设备**：分别选择两个实际发声的设备。
   - **延迟**：左右各有独立延迟（ms），用于补偿两台设备之间的物理延迟差；数值越大，该路声音越晚。
   - **启动延迟**：开始分流前的预缓冲时长，用于换取更稳的起播（低延迟 / 标准等档位）。
   - **音量**：左、右走端点音量（各自独立），主音量与增益走采样层。
   - **消音**：捕获端静音锁定——勾选后即使外部（系统音量条、快捷键、驱动）取消静音，也会被静默恢复。
   - **校正**：左右漂移闭环校正开关，默认开启。
   - **水位监控**：显示两侧缓冲水位与校正比例，用于诊断卡顿/延迟增长。
3. 点「开始分流」。停止或退出时会还原各端点的音量与静音快照。

窗口可关闭时最小化到托盘；二次启动会唤起已有窗口（单实例）。

## 目录结构

```
src/
  Audio/          抓取、延迟线、漂移校正（AudioEngine / DelayLine / DriftCorrectingProvider / DriftCorrectionShared）
  Devices/        设备枚举、端点音量绑定、默认设备变更监听
  Infrastructure/ 日志、崩溃上报、ini 配置存取、错误文案
  UI/             主窗体与自绘控件
docs/             改造方案、修改计划、回归测试清单
build.cmd         构建 + 内嵌资源校验 + 同步根目录 exe
verify.cmd        构建 + 工作区状态检查
```

运行日志写在 `log/session_*.log`，配置文件为 `SplitterGUI.ini`（均不入库）。

## 已知限制

- **不支持独占模式**：部分 USB 声卡标称 48 kHz 的实际采样率偏差可达 10%，超出 ±0.5% 的校正范围，强行独占会导致一侧被抽空直至静音，因此只使用共享模式。
- **蓝牙设备延迟较大且不稳定**，作为输出端时建议把延迟调大并使用较低的启动延迟档位。
- 左右延迟线共享同一捕获时间轴，调整一侧延迟不会改变另一侧的相对时序。
- 仅支持立体声（2 声道）输入；多声道源需先在系统侧下混。
